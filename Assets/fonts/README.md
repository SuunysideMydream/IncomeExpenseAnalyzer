# Local font

Inter Variable is distributed under the SIL Open Font License. The WOFF2 is the official normal variable font from [Inter](https://rsms.me/inter/); `Inter-OFL.txt` is the license from the [upstream repository](https://github.com/rsms/inter/blob/master/LICENSE.txt). The app serves the font locally and uses the system Thai font for glyphs outside its coverage.
